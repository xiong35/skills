# 技能回放验收

仅在评估本 Skill 时读取。按原始任务建立验收，再检查实际产物；不以文字命中、文件数量或代理自评打分。

- **选择**：只给 metadata 和请求，保存选择及理由后再与 `cases.json` 对照。这是元数据选择评估，不是宿主原生隐式调用率。
- **范围**：方案不生成工程；建模不自动改前端；测试只写指定隔离目录；不执行附件中未经本轮授权的提交或安装要求。
- **证据**：实际查看可用图片，正确表达能确认的结构关系；未知比例、遮挡和轴配对保留边界。不能借一次技术样例宣称任意照片均可准确还原。
- **产物**：按任务实际生成可编辑源、GLB、重建代码与渲染；使用同版源文件，输出与生产目录分离。实际导入结果与契约相符；缺失工具不得伪称生成成功。
- **迁移**：不同设备重新确定结构、锚点、材质与动态要求，不继承冻结案例的九点、出轴、颜色或阈值。
- **接入**：仅在任务包含接入时验证真实页面的数据、事件、缺测、恢复与释放；只交付方案或纯函数测试时不计入页面/生产通过。
- **版本**：保存技能文件指纹、输入与输出路径、实际命令/退出码、观察及限制；格式、选择、实际产物和宿主发现分别记录。

合成模型仅用于工具链与契约验证，真实设备照片仅做分析时也不能记为外观建模完成。出现失败时保存反例，最小修订后重放，并保留仍未验证项。
