# inspect-frontend 调查导航

仅调查 inspect-frontend 项目时读取。下列路径相对目标项目根目录，规则正文由项目原文档维护；本技能仓库不包含这些业务文件。

- 先在目标项目读取 `AGENTS.md`，确认 frontend、screen、uniapp 或 wixin。主应用再读 `frontend/AGENTS.md`。
- 涉及数据、权限、企业上下文、设备分发或实时事件，从 `frontend/README.md` 和上述指令的源码路径定位实际调用者。文档入口不等于运行证据。
- 按 `frontend/README.md` 的“检查与维护”选择当前可运行命令和浏览器场景；其他应用从自己的 package.json 和消费者出发。

典型调查的起点：

| 现象 | 优先区分的来源 |
| --- | --- |
| 企业/设备切换后数据串入 | 请求上下文创建时机、旧响应提交、页面复用与共享状态 |
| 页面返回后重复更新/资源泄漏 | 宿主及型号组件监听、轮询、异步加载和资源所有权 |
| 卡片/点标与模型位置异常 | 宿主缩放、投影转换、目标卡位、动画中间值和 DOM 尺寸 |
| 设备无数据或报警不一致 | 原始接口、适配状态、真实绑定、时间/单位和模块契约 |

相似现象可能来自不同机制，表格不是预设结论。缺生产接口时只证明隔离输入下的前端行为；不要借用其他设备编号或推定未知状态正常。
