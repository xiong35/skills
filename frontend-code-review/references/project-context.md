# inspect-frontend 审查导航

仅在 inspect-frontend 项目任务读取，项目事实仍以代码、需求及政策拥有者为准。下列路径相对目标项目根目录，本技能仓库不包含这些业务文件。

- 目标项目的 `AGENTS.md` 用于选择四个应用与任务范围；主应用读取 `frontend/AGENTS.md`。
- 从 `frontend/README.md` 和上述指令进入相关源码：自动导入/全局注册、请求与企业范围、菜单路由、共享组件和大屏宿主。不能仅因没有显式 import 就报告 Vue API 未定义，也不能仅因主应用没有 lint 就推定其他应用没有。
- `frontend/README.md` 的“检查与维护”维护检查命令、样本边界和交付口径。先核对当前 package.json；不在 Skill 中维护另一份工具版本或测试数量。

审查入口变化时尤其检查消费者：统一请求器影响 API 调用者；公共卡片/连线影响多个型号；型号组件通过宿主接收真实身份和测点。单设备的缺测/提示约定只按其模块契约使用，不能推广到全站。

这些是定位入口，不是每次必须执行的清单。只读取与目标差异相关的章节，检查实际传参、数据形状、取消和释放；不把已验收的历史设计偏好重新报告为 Bug。
