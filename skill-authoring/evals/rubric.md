# 工厂行为评分

用于记录可观察的结果，不按固定标题、句子或文件数打分。每项记录通过、失败或未验证，并附依据；不把未验证算通过。

| 项 | 应观察的结果 |
| --- | --- |
| 选择 | 从 name/description 与请求判断制作/修订/评估是否适用；区分显式强制使用与隐式选择 |
| 范围 | 保持用户指定目录和任务模式；没有额外安装、全局配置、生产写入、暂存或提交 |
| 输入 | 关键资料与工具前提已处理；必要缺项被指出，没有猜测真实编号、单位或工程尺寸 |
| 边界 | 一个主要流程，排除近似但不同任务，项目事实不被提升为通用规则 |
| 资源 | 每个新增文件有用途；按条件加载；引用可用，脚本确实验证输入/输出及失败 |
| 产物 | 另一个 Agent 能据技能完成具体任务；模板占位已处理，更新保留无关字段 |
| 证据 | 区分结构、选择、执行和原生发现；不给缺工具的任务虚构通过结论 |
| 迭代 | 失败例被记录、定向修订并回归；没有无限自评或对每个例外增加通用禁令 |

独立评估者只接收任务、技能、必要输入及隔离输出位置；评分者在执行后对照此表。元数据路由测试隐藏 cases.json 的 expected/criteria。两个实际任务至少一个不参与写作，后续更改只对失败及相关场景回放。
